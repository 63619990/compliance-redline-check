# 合规边界红线检查（Web3 防骗工具箱）

> 本技能由《价值互联网产业应用蓝皮书（2025）》经 cangjie-distill 蒸馏流水线提取编排，帮助普通用户识别真假 Web3、厘清合规边界、避开资金盘陷阱。

## 功能简介
境内 Web3/价值互联网项目在动手前的合规生死判读：什么能做（"非金融"的数字化赋能，如溯源、贡献计量、RDA 数据资产），什么绝对禁（代币化、稳定币、虚拟货币交易）。
  当用户在中国内地开展或参与 Web3 产业应用时激活：①不确定"发的到底是通证还是代币、会不会踩线"；②想用"境外合规"给境内业务找出口，或为境外项目提供账户/资金/技术；③涉及稳定币结算、面向境内居民募资、炒作升值预期；④内容科普/带货 Web3 项目需先判断是否会诱导非法金融。
  不适用于：纯境外持牌合规区且无境内要素的项目（转 S10）、纯术语/概念澄清（转 S1）、完全无上链/通证的纯传统业务。

## 安装方式

### 方式一：从 ClawHub 一键安装（推荐）
在 ClawHub 搜索 `compliance-redline-check`，或用 CLI：
```bash
clawhub skill install compliance-redline-check
```

### 方式二：从 GitHub 安装
```bash
git clone https://github.com/63619990/compliance-redline-check.git
cp -r compliance-redline-check/ ~/.workbuddy/skills/
```
重启 WorkBuddy 后，对话出现相关信号即自动激活。

### 方式三：手动安装
将本仓库 `compliance-redline-check/` 目录整体复制到 `~/.workbuddy/skills/`（Windows 为 `%USERPROFILE%\.workbuddy\skills\`）。
